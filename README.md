# 🎵 音乐分类管理器 (Music Classification Manager)

一个功能强大的音乐文件分类管理工具，使用Python和PyQt5开发，支持智能标签分类、批量文件管理和可视化操作界面。

![界面预览](https://img.shields.io/badge/界面-现代化-blue) ![Python](https://img.shields.io/badge/Python-3.7+-green) ![PyQt5](https://img.shields.io/badge/PyQt5-支持-orange)

## ✨ 主要功能

### 🎯 智能音乐分类
- **多标签支持**: 支持摇滚、流行、古典、爵士、电子、说唱、民谣、金属等多种音乐标签
- **自定义标签**: 用户可以自由添加和管理自定义标签
- **智能去重**: 基于文件哈希值自动识别重复文件，避免重复分类

### 📁 文件管理
- **批量操作**: 支持多选文件批量分类
- **文件预览**: 双击文件即可快速预览播放
- **时间排序**: 支持按修改时间从新到旧或从旧到新排序
- **文件统计**: 实时显示文件分类进度和统计信息

### 🎨 用户界面
- **现代化设计**: 采用现代化UI设计，操作直观
- **颜色编码**: 不同标签使用不同颜色，便于识别
- **响应式布局**: 自适应窗口大小，支持拖拽调整
- **中文界面**: 完全中文本地化，使用更便捷

### ⚡ 高级功能
- **撤销/重做**: 支持操作历史记录，可撤销和重做分类操作
- **文件夹状态**: 实时监控各标签文件夹的文件数量
- **配置保存**: 自动保存用户设置和分类记录
- **进度显示**: 分类操作时显示进度条，避免长时间等待

## 🚀 使用指南

### 第一步：选择音乐文件夹
1. 启动程序后，点击菜单栏的"文件" → "选择音乐文件夹"
2. 选择包含音乐文件的文件夹
3. 程序会自动扫描文件夹中的音乐文件

### 第二步：添加和管理标签
1. 在"标签管理"区域输入新标签名称
2. 点击"+ 添加"按钮创建新标签
3. 系统会自动为每个标签生成对应的文件夹

### 第三步：选择文件和标签
1. 在左侧文件列表中选择要分类的音乐文件（支持多选）
2. 在标签区域点击选择相应的标签（支持多选）
3. 已选标签会显示在"已选标签"区域

### 第四步：开始分类
1. 点击"🚀 开始分类"按钮
2. 确认分类操作
3. 等待进度条完成
4. 分类完成后文件会自动移动到对应的标签文件夹

### 第五步：查看结果
1. 在"分类统计"区域查看分类进度
2. 在"文件夹状态"区域查看各标签文件夹的文件数量
3. 双击文件夹项可以快速打开对应文件夹

## 📊 支持的音乐格式

程序支持以下常见的音乐文件格式：
- **MP3** (.mp3) - 最常用的音频格式
- **WAV** (.wav) - 无损音频格式
- **FLAC** (.flac) - 无损压缩音频
- **M4A** (.m4a) - Apple音频格式
- **OGG** (.ogg) - 开源音频格式
- **WMA** (.wma) - Windows媒体音频
- **AAC** (.aac) - 高级音频编码

## 🔧 技术架构

### 核心模块
- **MusicTagger类**: 主界面和业务逻辑
- **MusicFileItem类**: 音乐文件项数据模型
- **TagButton类**: 自定义标签按钮组件

### 文件处理
- **哈希去重**: 使用MD5哈希值识别重复文件
- **智能复制**: 自动处理文件名冲突
- **元数据保持**: 使用shutil.copy2保持文件元数据

### 用户界面
- **PyQt5框架**: 现代化的GUI框架
- **网格布局**: 整齐排列标签按钮
- **样式定制**: 自定义CSS样式美化界面

## 🐛 故障排除

### 常见问题

**Q: 程序无法启动**
A: 确保系统已安装必要的运行库，或尝试以管理员权限运行

**Q: 文件分类失败**
A: 检查文件权限和目标文件夹是否可写

**Q: 界面显示异常**
A: 尝试调整屏幕缩放比例或重新启动程序

**Q: 标签无法添加**
A: 确保标签名称不包含非法字符（\ / : * ? " < > |）
